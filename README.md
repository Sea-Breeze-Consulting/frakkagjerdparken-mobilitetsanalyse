# Frakkagjerdparken – mobilitetsanalyse

Interaktiv arbeidsflate for trafikk-, mobilitets- og tilgjengelighetsanalysen for Frakkagjerdparken i Tysvær.

Visualiseringen skiller mellom dokumenterte data, beregnede tillegg og analyser som fortsatt må gjennomføres. Den skal oppdateres når nettverksbaserte gangtider, Entur-reisetider, sykkelnett og arbeidsplassdata er ferdig analysert.
